# M3: missing-PHY defaults, sampled-node evidence and staged NAV

M3 is implemented and its three offline comparisons ran through the real generation CLI. Map B recall is 91.287%, versus 81.997% with the M2 bbox default. The staged Map A mesh at slope 0.55 with the unchanged M2 historical seed file has 31,769 areas, 131,484 directed links and 90.648% historical A-old recall, generated in 184.18 seconds.

The Map A mesh records the 160,909,364-byte input BSP in `bspSize`. It has not been loaded in game. Native traces and NextBot routes remain untested.

## Changes and evidence

`--missing-phy skip` is now the default in generation, scene loading, comparison and seed grounding. A SOLID_VPHYSICS prop with no PHY contributes no collision; `--missing-phy bbox` remains available explicitly. Genuine SOLID_BBOX props still use MDL boxes. Counts distinguish skipped missing-PHY instances from bbox fallbacks, and diagnostics name the chosen policy.

An isolated experiment tested this policy using M2 code and the same Map B inputs; its saved NAV hashes were checked against the saved generation records. Those runs support the default change on these assets; they are not independent proof of all Source/GMod runtime collision behavior. The box approximation can obstruct floors and create artificial walkable prop tops.

The fresh M3 Map B NAV is byte-identical to the experiment's M2 skip-at-0.7 NAV. That experiment recorded no separate code-tree hash; M3 records its own source hashes, actual CLI arguments and output hashes.

An ordinary-step link whose midpoint/drop/wider-portal probes all fail now needs a reciprocal sampled-node pair crossing the same shared edge. Both nodes must belong to the two final areas; existing cell ownership carries that provenance through merges and splits. The pair must straddle the edge and lie in its owned tangent interval. A connection without this witness is removed and counted as `removed_no_node_evidence`. Other traversal kinds retain the M2 audit policy. No-positive-width portals are still removed for all kinds.

The preserved M2 package was replayed with a read-only node audit; the resulting NAV hashes exactly match the originals. This checks the original unresolved links before changing collision policy:

|---|---|---|---|---|
| Map A .55 +old | 111 | 111 | 0 | True |
| Map B .70 | 1 | 1 | 0 | True |

The rule retains the original Map A links rather than deleting them speculatively. However, 103/111 selected witnesses have a node more than 18 units from the final area's interpolated height; the largest discrepancy is 60.596 units. Ownership proves sampled graph lineage, not fitted-height accuracy or native traversal. These discrepancies are a concrete native/area-fitting review target. Area fitting was not changed in M3. The audit records every original NAV ID, generation ID, node pair and position; the height-delta JSON records the measured offsets.

## Validation and remaining limits

28 tests pass in 25.421 seconds. New cases cover reciprocal direction/ownership, the actual shared edge, ownership after split+merge, unsupported ordinary-link removal with special-kind retention, and order-independent PHY bounds/thresholds. Original kernel/generation and engine-NAV round-trip fixtures still pass. The seed CLI exposes the explicit missing-PHY policy, and the three real generation CLI runs confirm the skip default. Each output is structurally validated and serializer-round-tripped before writing.

Remaining limits include collision/mount-order parity, area-height fitting and unresolved traversal; missing runtime/Lua entities and moving collision; non-brush model entities excluded from NPC-mask stair probes; transformed brush per-face surface flags; and deferred ladders/tactical/runtime links. The new default avoids invented missing-PHY boxes, but does not supply absent collision files. No production-readiness or native route-validity claim follows from these offline measurements.
